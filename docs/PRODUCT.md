# 产品契约

## 目标

公司内部知识库问答系统通过钉钉企业内部网页应用向员工提供“左侧知识库、右侧问答”的入口。系统只根据员工有权查看的公司知识生成带引用的回答，并在依据不足时明确拒答。

完整产品和钉钉接入方案见 `DINGTALK_RAG_DEVELOPMENT_PLAN.md`。

## 用户

- 员工：浏览有权知识空间、提问、查看引用和提交反馈。
- 知识管理员：维护被授权空间内的目录、文档、版本和 ACL。
- 系统管理员：管理应用配置、身份同步、任务、审计和健康状态；不因管理员角色自动获得全部文档内容。

## 产品不变量

1. 钉钉端内使用一次性免登码，由服务端换取稳定用户身份并建立本系统会话。
2. 未经授权的知识不进入检索候选、模型上下文、答案、引用和跨用户缓存。
3. 所有制度性结论必须能追溯到当前已发布文档版本。
4. 文档删除、撤回或失权后，原件、解析正文、向量、缓存和引用访问同步失效。
5. 默认文档私有；授权失败、权限同步失败和身份不确定时失败关闭。
6. PC 使用双栏布局；移动端保持完整问答能力并使用抽屉展示知识树。
7. 上传、解析、检索、会话和模型请求均有明确 payload/token 上限。

## MVP 范围

### 领导体验 MVP 0.1

- 使用完全虚构内容展示 PC 双栏、移动抽屉、问答、引用和资料不足状态。
- Spring API 与 Vue 页面可独立运行并进入统一 Harness。
- 不连接真实钉钉、公司资料、模型、数据库或对象存储。

该版本只验证产品形态和纵向工程链路，不代表生产 RAG、身份或 ACL 已完成。

### 首个业务可用 MVP

- 钉钉网页应用端内免登。
- 系统自管知识空间、目录、文档和 ACL。
- PDF、DOCX、Markdown、TXT 的解析、版本和索引。
- ACL 前置的混合检索、重排、引用和流式回答。
- 管理任务状态、审计元数据和离线 RAG 评测。

机器人、钉钉知识库增量同步、OCR 和复杂表格解析不属于第一阶段强制范围。
