# 安全与隐私边界

## 数据分类

- 高敏感：钉钉/App/模型/数据库凭据，Session，原始内部文档，解析正文，员工身份。
- 受限：员工问题、回答、引用、会话历史、文档 ACL、检索轨迹。
- 内部：脱敏汇总指标、无正文任务状态、模型延迟与成本。
- 公开：不含公司信息的代码、通用文档和完全虚构的测试夹具。

## 规则

- `.env`、密钥、`data/`、`uploads/`、`logs/` 和本地评测运行目录不进入 Git。
- 测试只使用 `example.invalid`、`test-user-*`、`DEPT_TEST_*` 和虚构制度文本。
- 身份和权限错误只返回稳定安全错误码，不返回钉钉原始响应、用户列表或文档存在性。
- ACL 在检索前应用；引用返回前再次校验当前文档版本和权限。
- 带私有上下文的缓存键包含主体与权限版本，不跨用户共享。
- 文档内容视为不可信数据；解析器禁用宏、脚本、外链执行和主动内容。
- 普通日志不记录 Token、免登码、原文、完整问题、完整回答或模型上下文。
- 模型调用只发送完成当前回答所需的最小授权片段，并受 token/字节预算控制。
- 删除/失权必须覆盖对象、正文、向量、缓存和预览；失败时文档保持不可检索。
- 默认自动化测试不访问钉钉、模型、数据库、Redis、对象存储和互联网。

## 变更审查

涉及认证、ACL、上传解析、检索、引用、缓存、删除、钉钉或模型调用的任务，交付时必须说明：读取范围、写入位置、日志内容、拒绝行为、payload 上限和测试证据。
