# Task: 智询可在受控服务器安全部署并限制两人试用

## 问题

用户已确认 Weekly Report 所在服务器可以承载智询，但当前钉钉认证只校验企业 `CorpId`，工作台可见范围无法阻止同企业其他员工通过直达 URL 登录；本机保存的两个服务器 SSH 入口目前都在密钥交换前被远端关闭。

## 范围

- 包含：钉钉稳定 `userId` 服务端白名单、名单外拒绝路径、Compose/示例配置和服务器部署说明、统一验证与双远端发布、连接恢复后的远端部署验收。
- 不包含：按姓名授权、自动采集员工 ID、开放式注册、生产数据库/Redis/MinIO、修改 Weekly Report、绕过管理员发布钉钉应用。

## 验收标准

- [x] 钉钉模式只有服务器配置的稳定 `userId` 可以建立 Session。
- [x] 白名单缺失时免登未就绪；名单外用户返回稳定 `403`，响应和日志不泄露名单。
- [x] CorpId、一次性免登码重放、CSRF 和现有 ACL/RAG 边界保持不变。
- [x] Compose 继续只暴露 `127.0.0.1:18080`，真实凭据和知识文件不进入 Git。
- [x] 统一验证通过，本地 Compose 健康。
- [ ] 服务器连接可用后完成远端健康、HTTPS、免登和模型调用验收。

## 约束

- 相关产品不变量：身份由服务端用免登码换取；工作台可见范围不能替代服务端授权；无权主体不得进入检索。
- 相关架构边界：Controller 只依赖 Service；名单判断位于认证 Service；钉钉与模型继续通过既有适配器调用。
- 需要保留的无关工作区修改：任务开始时工作区干净。

## 验证

- 单元/契约测试：54 个 Spring 测试通过，包含授权用户、名单外用户、缺失名单、错误 CorpId、免登码重放和演示模式拒绝。
- RAG 离线评测：3 个端到端和 4 个检索用例通过，越权文档/候选泄漏率均为 `0.0`。
- 手工/集成证据：本地 Compose 重新构建并保持两个容器健康，`/api/health` 返回 `UP/AGENTIC_RAG`；远端连接恢复后检查容器、反向代理、钉钉 PC/移动端和名单外直达 URL。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：使用严格、大小写敏感的钉钉稳定 `userId` 白名单；真实 ID 仅写服务器 `.env`。
- 数据读取/写入与日志：认证时只在内存比较钉钉返回的 `userId`；不记录免登码、用户 ID、名单或原始钉钉响应。
- 剩余风险：需要把管理员提供的应用凭据、两位测试者的稳定 `userId` 和 HTTPS 域名写入服务器私有配置；当前 SSH 入口在握手前关闭，尚未完成远端验收。
- 延后工作：多实例免登码防重放迁移 Redis；生产知识持久化组件和完整通讯录/ACL 同步。
