# Task: 重设计智询 MVP 前端视觉

## 问题

现有界面装饰性较强，深色大卡片、衬线标题和多层阴影削弱了企业问答产品的清晰感。需要在不改变认证和问答协议的前提下，重做为美观、高级、简约明晰的工作台。

## 范围

- 包含：桌面和移动布局、视觉变量、导航、空状态、消息、引用、输入区和认证入口样式。
- 不包含：后端 API、认证协议、ACL 行为、真实 RAG、品牌图标定稿和钉钉真机联调。

## 验收标准

- [x] 桌面端资料导航与问答主次清楚，不再依赖大面积装饰卡片。
- [x] 移动端导航抽屉、问答滚动和输入区可用。
- [x] 演示状态、授权范围、引用和资料不足状态仍有文字说明。
- [x] 现有认证、问答、引用和错误路径测试通过。

## 约束

- 相关产品不变量：PC 双栏、移动抽屉、带来源回答、无依据拒答。
- 相关架构边界：前端只展示后端授权结果，不承担数据权限裁决。
- 需要保留的无关工作区修改：Docker 部署基线、认证切片和 Harness。

## 验证

- 单元/契约测试：8 个 Vitest 通过，新增移动资料抽屉打开/关闭测试；15 个 Spring 和 10 个 Harness 测试继续通过。
- RAG 离线评测：保持固定虚构数据集不变。
- 手工/集成证据：Docker 生产构建达到 `healthy`；浏览器检查 1280×720 空状态、问答后状态、引用卡片与输入区，DOM 无错误；移动抽屉由交互测试覆盖，真机视觉留待钉钉联调。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：采用暖灰背景、白色信息层级、钴蓝主强调和现代中文无衬线排版；减少英文眉题、异形圆角和装饰阴影。
- 数据读取/写入与日志：不增加数据读写或前端日志。
- 剩余风险：钉钉 PC/Android/iOS WebView 字体渲染和安全区仍需真机确认。
- 延后工作：正式品牌图标、深色模式和个性化工作台。
