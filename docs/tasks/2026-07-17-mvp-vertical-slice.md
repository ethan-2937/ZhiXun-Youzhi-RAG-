# Task: 建立可演示的 Spring + Vue MVP 纵向切片

## 问题

仓库已有开发方案和 Harness，但没有业务工程。第一步需要建立 Spring Boot 与 Vue 基础工程，并提供领导可操作的双栏问答演示，而不是只有空脚手架。

## 范围

- 包含：Spring Boot 演示 API、Vue 双栏界面、虚构目录与引用、正常回答、无依据拒答、问题长度限制、前后端测试、构建和运行文档。
- 不包含：真实钉钉免登、真实文档上传、向量库、Embedding、LLM、生产 ACL、数据库和对象存储。

## 验收标准

- [x] 正常行为：领导可以选择示例问题，看到回答与来源卡片。
- [x] 身份/ACL/隐私行为：页面明确标注演示模式；只使用虚构内容，不暗示已接生产数据。
- [x] 失败行为和 payload 上限：未知问题明确资料不足；问题上限 1000 字并有后端测试。
- [x] Spring/Vue 测试和生产构建进入统一 Harness。

## 约束

- 相关产品不变量：带引用回答、无依据拒答、PC 双栏、移动抽屉。
- 相关架构边界：Controller 只依赖 Service 接口；前端不裁决权限。
- 需要保留的无关工作区修改：现有 Harness 与系统设计文档。

## 验证

- 单元/契约测试：5 个 Spring 测试、3 个 Vitest 和 10 个 Harness 测试通过。
- RAG 离线评测：3 个虚构固定用例通过，禁止来源/术语泄漏率均为 0。
- 手工/集成证据：浏览器验证桌面问答与引用、移动布局和资料抽屉；控制台 0 错误。视觉检查后修复侧栏横向滚动和回答自动定位。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：产品名采用“智询”；演示 API 与未来真实 RAG 适配器隔离，不让 Mock 实现渗入生产命名。
- 数据读取/写入与日志：只读内存虚构数据，不落盘问题和回答；浏览器验证只访问本机服务。
- 剩余风险：当前回答是确定性演示夹具，不能代表真实检索质量；Mockito 在当前 JDK 有未来动态 Agent 兼容警告，不影响本次测试。
- 延后工作：钉钉免登、真实 ACL、入库、模型链路和同源生产打包。
