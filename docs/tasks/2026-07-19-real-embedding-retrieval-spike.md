# Task: 接入真实 Embedding 与受限知识源检索

## 问题

当前问答只使用虚构关键词匹配。需要验证 OpenAI 兼容 Embedding 服务，并建立一个不依赖数据库的纵向切片，从批准的外部知识导出读取文档、分块、向量化、ACL 前置检索和返回引用。

## 范围

- 包含：真实 Embedding 适配器、JSONL 知识导入、分块、内存向量索引、用户 ACL 前置过滤、摘录式回答、引用、配置和失败路径测试。
- 不包含：生成式 ChatModel、PostgreSQL/pgvector、钉钉知识空间 API 增量同步、PDF/DOCX 解析、生产持久化和真实人员 ACL 配置。

## 验收标准

- [x] 默认测试和默认启动不访问真实模型或知识源。
- [x] 启用后可调用配置的 Embedding 服务并校验向量维度、数量、索引和有限数值。
- [x] 未授权文档在相似度计算前被过滤，不出现在回答或引用中。
- [x] 知识文件、文档、分块、批次、问题、摘录和回答均有上限。
- [x] 模型超时、错误响应、空知识、维度错误和无授权结果均失败关闭。

## 约束

- 相关产品不变量：ACL 检索前生效；回答必须有来源；依据不足明确拒答；模型输入有界。
- 相关架构边界：Controller 只依赖 Service；模型和知识文件位于 adapter 边界；真实正文和向量不进入 Git/日志。
- 需要保留的无关工作区修改：Docker、前端视觉、认证和 Harness。

## 验证

- 单元/契约测试：25 个 Spring 测试通过，覆盖 Embedding HTTP 契约、超限/超时/维度错误、知识源 ACL/字节限制、分块预算、ACL 泄漏和拒绝路径。
- RAG 离线评测：继续运行固定虚构评测集，真实运行输出不写回仓库。
- 手工/集成证据：只使用无公司信息的测试文本调用真实 Embedding，返回 1 条 1024 维向量、2 tokens，耗时约 627ms；Docker 默认关闭真实 RAG，健康检查和演示 Session/问答通过。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：真实 RAG 默认关闭；知识正文从未跟踪 JSONL 文件读取；本阶段只返回授权原文摘录，不调用未配置的生成模型。
- 数据读取/写入与日志：读取外部知识文件并发送有界分块/问题到配置的 Embedding 服务；只在内存保存向量；不记录正文、问题、向量或模型响应。
- 剩余风险：钉钉知识空间仍停在登录页，无法读取真实正文或确认导出/API 结构；真实配置尚未写入本机 `.env`，内存索引重启后重建，不适合大规模知识。
- 延后工作：钉钉知识 API、pgvector、文档版本/删除、混合检索、Reranker 和 ChatModel。
