# Task: Tailwind v4 身份页视觉试点

## 问题

当前 Vue 3 界面已有完整的全局 CSS 体系，但缺少 lint/typecheck 命令，身份确认页字号偏小、信息层级较弱。项目希望验证 Tailwind 的可维护接入方式，同时避免 Preflight 或工具类污染现有问答工作台。

## 范围

- 包含：Tailwind v4 最小隔离接入、AuthGate 身份页视觉重构、加载/错误/重试状态、前端 lint/typecheck、三档响应式视觉验收。
- 不包含：全量迁移现有 CSS、修改问答/资料预览业务行为、修改认证协议、增加组件库、暗色模式或获客页面优化。

## UI Contract

- 用户与任务：员工从钉钉或 MVP 浏览器进入应用，第一时间理解身份校验状态、资料权限边界，并在失败时完成重试。
- 信息层级：品牌与可信入口说明 -> 当前状态标题和说明 -> 主操作 -> 会话模式与安全边界提示。
- 布局：桌面为不对称双区入口面板；平板收紧间距并保持双区；375px 移动端改为单列，状态区在说明区之后，主要按钮保持至少 44px 高。
- 组件边界：只修改 `AuthGate.vue`；复用现有语义色变量，不改问答、资料树、预览和输入框组件。
- 视觉语言：暖灰画布、纸白表面、墨色正文、钴蓝动作色、琥珀错误色；以“授权知识路径”的线性节点作为唯一视觉锚点，不使用渐变光球或堆叠卡片。
- 字体与密度：沿用现有中文字体栈；正文不小于 14px，状态标题在桌面为 32px、移动端为 28px，辅助文字不小于 12px。
- 状态：加载、错误、重试、disabled、hover、active、focus-visible 均有文字和视觉反馈；颜色不是唯一状态信号。
- 无障碍：保留语义标题与 `role=alert/status`；键盘可聚焦重试按钮；长错误文案换行；视口缩小时无横向溢出。
- 视觉验收：375x812、768x900、1440x900 均能完整看到核心状态和操作；现有 18080 主工作台不因 Tailwind 接入发生布局变化。

## Motion Contract

- 入口面板：首次渲染使用 opacity + translateY，320ms，缓出；减少动态时立即显示。
- 状态切换：图标和文本只使用 180ms opacity/transform 反馈，不改变阅读顺序。
- 加载反馈：状态环旋转、进度条横向位移；同时显示“正在确认身份”，减少动态时改为静态进度标记。
- 重试按钮：hover/active 仅使用 160ms transform、background 和 shadow；键盘焦点始终可见。
- 明确不做：背景连续漂移、滚动动画、弹簧动画、第三方动效依赖。

## Tailwind Contract

- 版本：Tailwind CSS v4 + `@tailwindcss/vite`，与 Vite 7/Node 24 对齐。
- 隔离：使用 `tw:` 前缀；CSS 仅声明 theme 与 utilities，不加载 Preflight；内容扫描只指向 `AuthGate.vue`。
- Token：复用 `--ink`、`--muted`、`--canvas`、`--blue` 等现有语义变量；不引入第二套暗色或品牌策略。
- 迁移：只移除 `auth.css` 的入口并迁移身份页；其余全局 CSS 保持原样。

## 验收标准

- [x] 正常行为：加载和错误页按契约渲染，重试事件仍可触发。
- [x] 身份/ACL/隐私行为：只展示后端返回的状态文案，不改变身份或 ACL 裁决。
- [x] 失败行为和 payload 上限：长错误文案不溢出；不增加网络 payload 或持久化数据。
- [x] Tailwind 不引入 Preflight，主工作台保持原布局。
- [x] lint、typecheck、test、build 和三档浏览器视觉验收通过。

## 约束

- 相关产品不变量：前端不承担权限裁决；移动端保留完整入口能力；颜色不能替代文字状态。
- 相关架构边界：组件不复制 API 调用；认证流程仍由 `useAuth` 与后端接口负责。
- 需要保留的无关工作区修改：任务开始时工作区干净。

## 验证

- 单元/契约测试：ESLint、`vue-tsc`、12 个 Vitest 用例和 52 个 Spring 用例通过；新增 2 个 AuthGate 状态/重试测试。
- RAG 离线评测：视觉试点不改变 RAG，但统一验证必须通过。
- 手工/集成证据：375x812、768x900、1440x900 均无横向溢出；加载/错误/重试、键盘焦点和 reduced-motion 通过；主工作台桌面/移动回归无布局变化；控制台无错误或警告。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：采用 Tailwind 4.3.3 Vite 插件、`tw:` 前缀、仅 AuthGate 内容扫描、无 Preflight；将 lint/typecheck 纳入统一 Harness。
- 数据读取/写入与日志：不增加业务数据读取、写入或日志。
- 剩余风险：Tailwind 仍处于单页面试点，后续页面迁移需逐页复核全局 CSS 优先级。
- 延后工作：问答工作台全量视觉升级、现有 CSS 分层治理和视觉回归自动化。
