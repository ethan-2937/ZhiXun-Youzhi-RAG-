# Task: 检索评测与诊断 v2 可量化调优

## 问题

当前 RAG 只有 3 个端到端虚构冒烟用例，无法量化分块、TopK、相似度阈值和未来混合检索的变化。现有问答接口只返回最终引用，不暴露受控的候选排名与分数，因此无法进行错误归因和离线参数扫描。

## 范围

- 包含：检索数据集/预测契约；Recall@K、MRR、nDCG、拒答、越权、重复率和延迟指标；阈值/TopK 扫描；报告比较；默认关闭、ACL 前置且无正文的本地诊断接口；本地预测采集器。
- 不包含：生产可见诊断接口；真实问题入 Git；BM25、Reranker、ChatModel；自动修改线上参数。

## 验收标准

- [x] 正常行为：固定候选结果可重复评分、扫描 TopK/阈值并比较基线与候选。
- [x] 身份/ACL/隐私行为：诊断候选在打分前按稳定用户 ID 和空间过滤；响应与产物不包含正文；越权候选是硬失败。
- [x] 失败行为和 payload 上限：诊断默认关闭；问题、候选数、文件、行、案例数和候选数均有上限；缺失/重复/未知案例失败可见。
- [x] 默认自动测试不访问真实模型、钉钉或互联网。

## 约束

- 相关产品不变量：ACL 在检索前生效；无权文档不得进入候选、日志或评测产物。
- 相关架构边界：Controller 只依赖 Service 接口；诊断复用正式检索排序逻辑，不创建旁路索引。
- 需要保留的无关工作区修改：当前 `main` 干净且已同步两个远端。

## 验证

- 单元/契约测试：诊断 ACL、关闭状态、无候选不调用模型、请求上限、指标计算、参数扫描和比较。
- RAG 离线评测：新增完全虚构检索样例并保持原端到端评测通过。
- 手工/集成证据：本地启用诊断后采集受控样例，确认响应不含正文。
- 统一命令：`powershell -ExecutionPolicy Bypass -File scripts/verify.ps1`

## 交付

- 决策：诊断路由只在演示认证、RAG 和独立诊断开关同时启用时注册；正式回答与诊断复用同一个 ACL 前置排序方法。候选记录只包含 rank、documentId、chunkId、score，阈值在离线评分时应用。
- 数据读取/写入与日志：采集器只接受当前演示主体的数据集，单响应最多 512 KiB、单集最多 1 MiB/500 例；预测原子写入 `harness/retrieval-evaluation/runs/`，普通输出只报告数量和稳定错误码。
- 验证：统一 Harness 全部通过（28 个 Python 测试、36 个 Spring 测试、9 个 Vue 测试及生产构建）；Docker 真实本地索引采集 1 例/5 个候选，字段白名单通过；恢复默认配置后容器健康且诊断路由返回 404。
- 剩余风险：当前固定提交集只有 4 个虚构用例，尚不足以代表真实问题分布；进程内穷举向量索引的延迟和容量不能代表未来 pgvector；候选分数还没有跨模型校准。
- 延后工作：经批准的脱敏评测集、混合检索、Reranker、索引版本对比和管理端可视化。
